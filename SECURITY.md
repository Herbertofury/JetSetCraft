# Security policy

Please report vulnerabilities privately through [GitHub's security advisory form](https://github.com/Herbertofury/JetSetCraft/security/advisories/new). Do not include exploit details, private server data, tokens, or personal information in a public issue.

The currently supported line is `0.3.x` for Minecraft 1.20.1. Reports should include the exact JetSetCraft, Forge, Java, Minecraft, and optional-mod versions; relevant logs; reproduction steps; and whether the behavior occurs on a dedicated server, client, or both.

# Contributing

Issues and focused pull requests are welcome. Before opening a pull request:

1. Use Java 17 and the checked-in Gradle wrapper.
2. Preserve server authority, momentum continuity, combat input ownership, source-mob identity, and optional-mod isolation.
3. Record provenance and rights for every external asset; never commit secrets, game binaries, mod JARs, or unlicensed material.
4. Run every validator listed in the README, `gradlew.bat clean build`, and `gradlew.bat runGameTestServer` (or the Unix wrapper equivalents).
5. Update tests and documentation when behavior or configuration changes.

By contributing, you affirm that you have the right to submit the material. A contribution does not change the project's license unless the copyright holder explicitly agrees in writing.

# JetSetCraft Project Compass

## Northpoint
Build the best full street-movement experience possible inside Minecraft: momentum-first skating/rollerblading/quad skating/skateboarding/BMX, tricks, grinding, wall riding, boost, graffiti and combat that all work together rather than as isolated minigames.

## Hard guardrails
- Combat never becomes a hidden locomotion-cancel button.
- Ride animation defaults to lower-body ownership so weapons can animate naturally.
- Server-authoritative physics and real-world collision geometry remain the foundation.
- Core equipment must read as deliberately modeled 3D gear, never placeholder cubes.
- 1.20.1 is the first fully proven target; multi-version work follows a stable architecture.
